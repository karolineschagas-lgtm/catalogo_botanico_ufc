# 🌿 Catálogo Botânico

### Inventário Florístico do Setor de Abelhas do Campus do Pici – UFC

## 📖 Sobre o projeto

O Catálogo Botânico é um sistema desenvolvido com o objetivo de organizar e disponibilizar informações sobre as espécies vegetais presentes no setor de Abelhas do Campus do Pici, da Universidade Federal do Ceará (UFC).

A plataforma permite consultar informações botânicas das plantas catalogadas, contribuindo para a organização e divulgação do conhecimento sobre a diversidade vegetal da área.

## ✨ Funcionalidades

- Consulta de espécies vegetais cadastradas.
- Visualização de informações botânicas.
- Cadastro de novas plantas.
- Edição e exclusão de registros.
- Área administrativa com acesso restrito.
- Armazenamento de informações em banco de dados.

## 🛠️ Tecnologias utilizadas

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## 💻 Execução do projeto

1. Instale o XAMPP.
2. Coloque a pasta do projeto dentro do diretório `htdocs`.
3. Inicie o Apache e o MySQL.
4. Importe a estrutura do banco de dados no phpMyAdmin, utilizando o arquivo SQL disponibilizado separadamente.
5. Configure a conexão com o banco de dados.
6. Acesse o projeto pelo navegador através de `http://localhost/catalogo_botanico/`.
